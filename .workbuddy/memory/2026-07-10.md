## Zeabur 部署适配
需求：把项目部署到 Zeabur。
- **核心坑**：本地 `python app.py` 靠 `__main__` 调 init_db()，但 gunicorn 不走 __main__ → 表建不出来 → 线上首请求 500。解决：把 `init_db()` 提到 app.py 模块级（app.secret_key 之后），幂等，try/except 包裹。
- requirements.txt 加 `gunicorn>=21.2.0`。
- models.py 在 DB_PATH 定义后加 `os.makedirs(dirname(DB_PATH), exist_ok=True)`（云端容器无 data/ 目录会导致 sqlite 连接失败）。
- 新建 `zbpack.json`：`{"start_command":"gunicorn app:app -b 0.0.0.0:$PORT --workers 2 --timeout 120"}`。
- 新建 `.gitignore`（忽略 *.db / __pycache__ / reports/*.html），data/ 与 reports/ 加 .gitkeep 保留空目录。
- git init + 两次提交完成，待用户 `git remote add` + push。
- **持久化警告**：Zeabur 容器磁盘临时，必须挂 Volume 到 `/src/data`，否则 SQLite 数据重部署即丢。
- 环境变量：FLASK_SECRET_KEY 必设；钉钉 AppKey/Secret 可选（一旦设置会启用登录门禁，需同时设 APP_BASE_URL 并在钉钉后台加回调白名单）。
- 验证：test_client import app 后 GET /api/dashboard → 200，WSGI 对象 app.app 为 Flask 实例，gunicorn `app:app` 可加载。
- 部署说明写入 `Zeabur部署指南.md`。无法远程代操作 Zeabur（无连接器），交付配置 + 手册。
